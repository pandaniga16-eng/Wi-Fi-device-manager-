📶 Wi-Fi Device Manager

Review devices and manage your network securely.

Network status

● App is running

This app cannot automatically scan your Wi-Fi or disconnect devices. Real device information and blocking require supported router controls and permission from the router administrator.

Connect to router settings

On your iPhone, open Settings → Wi-Fi → tap ⓘ beside the connected network. Find the Router address and enter it below.

Device records

Add devices you identify from the router's official connected-device list. These are saved records, not a live network scan.

Block an unwanted device

Deleting a record below only removes it from this app. To block a real device, the router administrator must use a supported feature such as Access Control, Device Management, or a Block List.

If you only have the Wi-Fi password, ask your dad or the internet provider for help with administrator access.
